InfinityFree-e upload korar niyom
1. Client Area > Control Panel > Online File Manager (ba FileZilla) khulun.
2. htdocs folder-er bhetorer default file (index2.html ityadi) muchhe din.
3. Ei zip extract kore shob file ar icons folder htdocs-e upload korun (index.html, manifest.json, sw.js, icons/).
4. Client Area theke Free SSL (HTTPS) chalu korun. HTTPS na hole install korar option ashbe na.
5. Phone-er Chrome-e https://apnar-site-link kholun > menu > Install app / Add to Home screen.
